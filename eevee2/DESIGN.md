# 이브이 타워디펜스 v2 - 기획서

> 현재 버전: v1.67 (CHANGELOG.md 참고)

## 게임 개요
이브이들을 배치/육성하여 농장으로 몰려오는 몬스터를 막아내는 타워디펜스 게임.
- 캔버스: **480x960** (모바일 세로)
- PC(마우스) / 모바일(터치) 지원
- 평면 아이소메트릭 시점 (`ISO_Y = 0.7` Y축 압축)
- 60FPS 고정 (고주사율 모니터 호환)

## 핵심 컨셉
```
몬스터가 5방향(좌/좌하/하/우하/우)에서 진입
  → 농장 둘레(타원 궤도)를 시계방향으로 순회
  → 이브이들이 농장 안에서 자동공격 + 자율 배회
  → 라운드 시간 종료 시 즉시 다음 라운드 (연속 진행)
  → 골드로 이브이 추가/진화/레벨업
  → 보스/레이드 처치 시 아이템 드롭
  → 과포화 발생 → 다음 라운드 종료까지 정리 못 하면 패배
```

### 밤낮 보너스 (타입 패시브)
- **☀ 낮 강화 (+20%)**: fire, grass, normal, rock, ground, bug, flying
- **☾ 밤 강화 (+20%)**: dark, ghost, ice, psychic, poison, fairy, dragon
- **중립**: water, electric, fighting, steel
- 트리거 시 작은 빛 링 + 반짝 파티클 (텍스트 X)

### 시그니처 스킬 오버라이드 (`dayMul`/`nightMul`)
스킬에 명시 시 타입 패시브를 덮어씀.
- **솔라빔**: 낮 ×1.6 / 밤 ×0.6 (원작 매커닉)
- **오버히트/대폭발**: 낮 ×1.35 / ×1.4
- **눈보라/블리자드**: 밤 ×1.35 / ×1.45
- **나이트헤드**: 밤 ×1.6 / 낮 ×0.7
- **폭풍**: 밤 ×1.5
- **악의파동/미래예지/맹독/섀도우볼**: 밤 강화
- **에어슬래시/이중바위/씨폭탄**: 낮 강화

## 게임 시작 흐름
1. **스플래시 화면** (이브이즈 + TOP 3 + 버전)
2. 첫 실행: **인터랙티브 튜토리얼** (5단계)
3. 두 번째부터: 탭하면 바로 게임
4. 우측 하단 ? 버튼으로 튜토리얼 재시작 가능

## 이브이 시스템

### 조작
- **탭**: 선택 (점선 링)
- **드래그**: 이동 (이브이 또는 바위)
- **드래그 → 우측 상단 판매 슬롯**: 이브이 판매
- 미배치 시에도 자동 배회
- 드래그 중 농장 경계 클램프
- 이브이끼리 충돌 분리 (겹침 방지)

### AI 우선순위
1. 사거리 ×1.5 안에 몬스터 있음 → 타겟
2. 사거리 안 → 정지 + 평타
3. 사거리 밖 → 1.3배속 추적
4. 타겟 없음 → 농장 안 배회

### 시작 상태
- 이브이 1마리, 골드 50

### 추가 구매
- 하단 바 `+ 이브이` 버튼 (`30 + eeveesBought × 5` 골드)
- **슬롯 캡**: `3 + floor(wave/3)`, 최대 **20**
- W0:3, W3:4, W6:5, W9:6, W12:7 …

### 판매 / 친밀도 재테크
- 이브이 드래그 → 우측 상단 판매 슬롯에 떨구기
- 환불: 기본 이브이 15g, 진화체 50g + 누적 레벨업 비용 ×0.5
- **친밀도 5단위 판매 배수 (기본 이브이 한정)**:
  | 친밀도 | 배수 |
  |---|---|
  | 0~4 | ×1 |
  | 5~9 | ×5 |
  | 10~14 | ×10 |
  | 15~19 | ×15 |
  | 20~24 | ×20 |
- F5부터 명확한 흑자 → 진화 vs 재테크 트레이드오프
- 진화체는 친밀도 시스템 적용 X (진화 시점에 결정)

## 레벨 시스템
- 이브이마다 `level`, `baseAtk/baseSpAtk/baseAtkSpeed/baseRange` 보유
- 좌측 액션 패널의 `▲ 레벨업` 버튼 (선택 시 표시)

### 비용
- 기본 이브이: `15 + (lv-1)*8 + (lv-1)²*0.6`
- 진화체:    `40 + (lv-1)*20 + (lv-1)²*1.5`

### 효과 (가산식)
- 진화체: lv당 ATK +16%, 공속 -3%
- 기본 이브이: lv당 ATK +8%, 공속 -1.5% (진화 유도)
- **머리 위 노란 배지**로 레벨 표시
- **진화 시 레벨 1로 리셋**

### 나인이볼부스트 (기본 이브이 Lv50 패시브)
- Lv50 도달 시 자동 발동, 반경 150 안 모든 이브이즈 10초:
  - 모든 스킬 쿨다운 즉시 초기화
  - ATK/spAtk ×1.5
  - 사거리 ×1.3, 공속 ×0.65

## 일반공격 vs 스킬

### 일반공격 (평타)
- 매 `effSpd` 프레임마다 1회
- atk 사용, 몬스터 mDef로 방어
- 항상 phys 카테고리
- **평타 스플래시**: 반경 22, 메인 데미지 ×0.30

### 스킬 (진화체별 3개)
- **Lv5**: Ⓟ (phys)
- **Lv10**: Ⓢ (spec)
- **Lv15**: Ⓤ (ult)
- 발동: 평타 시점에 6% 확률 + 쿨다운 OK
- 첫 사용은 쿨다운 절반에서 시작 (빠른 첫 발동)

### 스플래시 데미지
- single / melee / dash / chain / pierce / delayed 스킬은 적중 위치에 **반경 25 스플래시** (40% 데미지)
- aoe / buff / field는 자체가 광역이라 스플래시 X
- 평타 스플래시: 반경 22, 30%

### 데미지 공식
```
물리 = max(1, atk × mul - mDef × 0.3) × 타입상성 × 밤낮배수
특수 = max(1, spAtk × mul - sDef × 0.3) × 타입상성 × 밤낮배수
```

### 상태이상
| 상태 | 효과 |
|---|---|
| 화상 (burn) | 30프레임마다 DOT |
| 독 (poison) | 30프레임마다 DOT |
| 빙결 (freeze) | 이속 40% (느림) |
| 마비 (paralysis) | 이속 0 (정지) |
| 잠듦 (sleep) | 이속 0 (정지) |
| 둔화 (slow) | 이속 60% |
| 물리방어 감소 (mDefDown) | mDef -30% |
| 특수방어 감소 (sDefDown) | sDef -30% |

상태이상 걸린 몬스터에 외곽 글로우 오라 + 약한 색상 틴트.

## 게임오버 (유예 라운드 시스템)

- UI:
  - 첫 초과 라운드: 주황 경고 "다음 라운드 종료까지 정리해야 한다"
  - 유예 라운드: 빨강 경고 "마지막 기회!"
- 컷신: 몬스터들이 농장 안쪽으로 침투 + 떨림 + "농장이 침입당했다!"

## 글로벌 아이템 (보스 드롭)
보스 처치 시 25% (레이드 100%) 확률로 미보유 아이템 1개 드롭. 글로벌 패시브.

| 아이템 | 효과 |
|---|---|
| 달인의띠 | 효과적 상성 ×1.2 → ×1.3 |
| 광각렌즈 | 모든 이브이즈 사거리 +15% |
| 박식안경 | 특수공격(spAtk) +25% |
| 예리한이빨 | 평타 15% 크리티컬 (×1.6) |
| 빛의점토 | 바위 버프 반경 ×1.5 |
| 선제공격발톱 | 이브이즈 공속 +15% |
| 울퉁불퉁멧 | 진입 중 몬스터 매초 도트 |
| 초점렌즈 | 별로(×0.8) → ×0.9 |
| 겨냥표적 | 평타 20% 더블샷 |

각 아이템은 특정 팬메이드 진화의 조건이기도 함:
- 빛의점토 → 거다이브
- 박식안경 → 메가브이
- 초점렌즈 → 메탈리아
- 울퉁불퉁멧 → 샌디온

## 골드/경제
- 시작 골드: 50
- 일반 처치 보상: `6 + floor(wave * 1.0)`
- 보스 처치 보상: `60 + wave * 12`
- 레이드 처치 보상: `150 + wave * 20`
- **라운드 클리어 보상**: 진입한 라운드 번호만큼 골드 (W2 → +2, W10 → +10)
- 사용처: 이브이 추가 / 진화 / 레벨업

## 인터랙티브 튜토리얼 (5단계)
첫 실행 시 자동 표시. localStorage `eevee2_tutorial_seen` 저장.
1. **이브이 탭** — 선택
2. **드래그 → 목표 지점 (◎)** — 농장 우측 펄스 원형으로 이동
3. **자동 공격** — 차곡차곡 1마리 자동 등장 → 처치
4. **레벨업** — 좌측 ▲ 강조, 1회 레벨업
5. **이브이 추가** — + 이브이 버튼 강조, 1회 추가 → 자동 게임 시작

- 우측 하단 **스킵** 버튼
- 튜토리얼 중 웨이브/과포화 비활성

- **상단 좌측**: 낮/밤 배지, 인벤토리, 🏆 리더보드
