# 이브이 타워디펜스 v2 - 기획서

## 게임 개요
이브이들을 배치/육성하여 농장을 순회하는 몬스터를 제한시간 내 처치하는 타워디펜스 게임.
- 캔버스: **640x800** (세로 모바일)
- PC(마우스) / 모바일(터치) 지원
- 평면 아이소메트릭 시점 (`ISO_Y = 0.5` Y축 압축)

## 핵심 컨셉
```
몬스터가 화면 우측에서 진입
  → 농장 둘레(타원 궤도)를 시계방향으로 순회
  → 이브이들이 농장 안을 자유롭게 돌아다니며 자동공격
  → 제한시간 내 모든 몬스터 처치 → 웨이브 클리어
  → 골드 획득 → 이브이 추가/진화/레벨업
  → 실패 시 몬스터 침입 → 게임오버
```

## 좌표계
- 전체 게임이 평면 아이소메트릭 좌표계를 공유
- `ISO_Y = 0.5` 상수로 Y축을 절반 압축
- 원형 궤도/사거리/농장은 모두 타원형으로 표현
- 깊이 정렬은 Y좌표 기준 painters algorithm

## 농장
- 타원형 평면 플랫폼 (X반경 180, Y반경 90)
- 잔디 타일 + 돌 테두리 + 타원형 나무 울타리
- 장식: 건초더미, 나무상자, 물통, 꽃
- 이브이는 농장 안에서만 배치/이동 가능

## 배경
- RPG 풀탑뷰 스타일 (오프스크린 캔버스 사전 렌더)
- 잔디 다이아몬드 타일, 흙길, 가장자리 절벽(돌벽)
- 둥근 나무 (Y정렬), 우하단 물 웅덩이
- 잔디 디테일 + 작은 꽃 + 구름 그림자 애니메이션

## 이브이 시스템

### 조작
- 유저가 드래그앤드롭으로 위치 지정 (수동 배치)
- 미배치 시에도 자동으로 농장 안 배회 (랜덤 목적지 ↔ idle)
- 탭하면 선택 (점선 링 표시) → 액션 패널 표시
- 드래그 중 공격 비활성화 + 사거리 표시

### AI 우선순위
1. 사거리 내 타겟 → 공격 (이동 멈춤)
2. 사거리 밖 타겟 존재 → 1.3배속 추적
3. 타겟 없음 → 농장 안 배회

### 시작 상태
- 이브이 1마리 (이브이.png), 골드 30

### 추가 구매
- 하단 바 `+ 이브이` 버튼
- 가격: `40 + 구매수 * 30` (점진 증가)

### 낮/밤 시스템
- 홀수 웨이브 = 낮 ☀
- 짝수 웨이브 = 밤 ☾
- 친밀도 진화 시 시간대에 따라 에브이/블래키 결정

### 일반공격 vs 스킬공격
- **일반공격** = 평타 = 물리 카테고리 (atk 사용)
  - 몬스터 mDef 로 방어
- **스킬공격** = 진화체별 고유 스킬 2개 (물리 + 특수)
  - 자동 발동 (쿨다운 + 사거리 내 타겟)
  - 물리 스킬: atk × mul, mDef로 방어
  - 특수 스킬: spAtk × mul, sDef로 방어
  - 이펙트: single(단일) / aoe(광역) / chain(연쇄)
  - 첫 사용은 쿨다운 절반에서 시작 (빠른 첫 발동)

### 레벨 시스템 (NEW)
- 이브이마다 `level`, `baseAtk/baseAtkSpeed/baseRange` 보유
- 탭 → 좌측 액션 패널의 `▲ 레벨업` 버튼으로 강화
- 비용: `20 + (level - 1) * 15` 골드
- 능력치 상승 (소량):
  - ATK: `baseAtk * (1 + 0.15 * (level - 1))`
  - ATK SPEED: `baseAtkSpeed * (1 - 0.04 * (level - 1))` (최소 8)
  - RANGE: `baseRange * (1 + 0.05 * (level - 1))`
- 머리 위 노란 배지로 레벨 표시 (Lv.2 이상)
- **진화체 전용 레벨 디자인은 추후 처리**

## 몬스터 시스템

### 행동
1. 화면 우측 밖에서 진입 (속도 비례 진입)
2. 농장 궤도(타원)에 도달하면 시계방향 순회
3. 이브이 공격으로 HP 0 → 사망 → 골드 드롭

### 데미지 공식
```
물리데미지 = max(1, atk - mDef * 0.3) * 타입상성
특수데미지 = max(1, spAtk - sDef * 0.3) * 타입상성
```

### 타입 상성
- 18타입 전체 상성표 적용 (TYPE_CHART)
- ×2.0 → "효과적!"
- ×0.5 → "별로..."
- ×0   → "효과없음"

### 웨이브 스탯 스케일링
```
waveMul = 1 + (wave - 1) * 0.2   (웨이브당 +20%)
HP = baseHp * waveMul * (0.85~1.15)
DEF = baseDef * waveMul * 0.12
SPD = spdBase(0.003) * (baseSpd / 100)
```

## 웨이브 시스템
| 구간 | 몬스터 수 | 해금 |
|---|---|---|
| W1-2 | 2+w | 차곡차곡만 |
| W3-5 | 3+w | 점진 증가 |
| W6-10 | 5+w | 절반 ~ 전체 |
| W11+ | 8+w | 전체 |

- **5의 배수 웨이브**: 일반 보스 (HP 4배, 잡몹 60%)
- **10의 배수 웨이브**: 재앙 포켓몬 (HP 8배, 잡몹 40%)
- 제한시간: 30초/웨이브
- 클리어 → 3초 대기 → 자동 다음 웨이브
- 시간 초과 + 몬스터 잔존 → 침입 컷신 → 게임오버

## 골드/경제
- 시작 골드: 30
- 몬스터 처치 시 `5 + wave * 2` 골드 (팝업 텍스트 표시)
- 사용처: 이브이 추가, 진화, 레벨업

## HUD
- **상단 중앙**: 웨이브 배지 + 카운트다운 + 남은 몬스터 수
- **상단 우측**: 골드 표시
- **하단 바**: `+ 이브이` 구매 버튼, 보유 마릿수
- **선택 시 좌측**: 액션 패널 (Lv.X + ▲ 레벨업 버튼)
- **선택 시 하단**: 진화 패널(이브이일 때) / 스탯 정보(진화체일 때)
- **웨이브 대기**: 카운트다운 표시
- **컷신**: 농장 침입 + "농장이 침입당했다!"
- **게임오버**: 도달 웨이브 + 터치 재시작
