# 이브이 타워디펜스 v2 - 기획서

> 현재 버전: v1.25 (CHANGELOG.md 참고)

## 게임 개요
이브이들을 배치/육성하여 농장으로 몰려오는 몬스터를 막아내는 타워디펜스 게임.
- 캔버스: **640x800** (세로 모바일)
- PC(마우스) / 모바일(터치) 지원
- 평면 아이소메트릭 시점 (`ISO_Y = 0.7` Y축 압축)
- 60FPS 고정 (고주사율 모니터 호환)

## 핵심 컨셉
```
몬스터가 화면 8방향에서 진입
  → 농장 둘레(타원 궤도)를 시계방향으로 순회
  → 이브이들이 농장 안에서 자동공격 + 자율 배회
  → 라운드 시간 종료 시 즉시 다음 라운드 (연속 진행)
  → 몬스터가 일정 수 이상 또는 보스 2+ → 카운트다운 → 게임오버
  → 골드로 이브이 추가/진화/레벨업
  → 보스/레이드 처치 시 아이템 드롭
```

## 좌표계 / 카메라
- 평면 아이소메트릭 (`ISO_Y = 0.7`)
- Y축 0.7 압축으로 살짝 위에서 내려보는 시점
- 원형 궤도/사거리/농장 → 모두 타원형
- 깊이 정렬: Y좌표 기준 painters algorithm

## 농장
- 타원형 평면 플랫폼 (X반경 180, Y반경 ≈126)
- 잔디 타일 + 돌 테두리 + 타원형 나무 울타리
- 장식: 건초더미, 나무상자, 물통, 꽃
- 이브이는 농장 안에서만 배치/이동 가능

## 배경
- RPG 풀탑뷰 스타일 (오프스크린 캔버스 사전 렌더)
- 잔디 다이아몬드 타일, 흙길, 가장자리 절벽
- 둥근 나무 (Y정렬), 우하단 물 웅덩이
- 잔디 디테일 + 작은 꽃 + 구름 그림자 애니메이션
- **밤** 시간대에는 어두운 파란 오버레이 + 별

## 낮/밤 시스템
- 3웨이브씩 토글 (W1-3 ☀ 낮, W4-6 ☾ 밤, ...)
- 시각: HUD 좌측 상단 배지 + 화면 톤 변화
- 친밀도 진화 시 시간대에 따라 에브이/블래키 결정

## 게임 시작 흐름
1. **스플래시 화면** (이브이즈 일렬 흔들거림 + TOP 3 + 버전)
2. 첫 실행: **인터랙티브 튜토리얼** (5단계, 후술)
3. 두 번째부터: 탭하면 바로 게임
4. 우측 하단 ? 버튼으로 튜토리얼 재시작 가능

## 이브이 시스템

### 조작
- **탭**: 선택 (점선 링)
- **드래그**: 이동 (이브이 또는 바위)
- **드래그 → 우측 상단 판매 슬롯**: 이브이 판매
- 미배치 시에도 자동 배회 (랜덤 목적지 ↔ idle)
- 드래그 중 농장 경계 클램프
- 이브이끼리 충돌 분리 (겹침 방지)

### AI 우선순위
1. 사거리 ×1.5 안에 몬스터 있음 → 타겟
2. 사거리 안 → 정지 + 평타
3. 사거리 밖 → 1.3배속 추적
4. 타겟 없음 → 농장 안 배회

### 시작 상태
- 이브이 1마리, 골드 50

### 추가 구매
- 하단 바 `+ 이브이` 버튼 (30 골드 고정)
- **슬롯 캡**: `2 + floor(wave/5)`, 최대 **20** (정식 8 + 팬메이드 11 + 1)

### 판매
- 이브이 드래그 → 우측 상단 판매 슬롯에 떨구기
- 환불 가격: 기본 이브이 15g, 진화체 50g + 누적 레벨업 비용의 50%

## 레벨 시스템
- 이브이마다 `level`, `baseAtk/baseSpAtk/baseAtkSpeed/baseRange` 보유
- 좌측 액션 패널의 `▲ 레벨업` 버튼 (선택 시 표시)

### 비용
- 기본 이브이: `15 + (lv-1) * 8`
- 진화체: `40 + (lv-1) * 20`

### 효과 (복리)
- ATK / spAtk: ×1.16 / lv (Lv10: ×3.80)
- 공속: ×0.94 / lv
- 사거리: ×1.05 / lv
- **머리 위 노란 배지**로 레벨 표시 (Lv2 이상)
- **진화 시 레벨 1로 리셋**

### 나인이볼부스트 (기본 이브이 Lv50 패시브)
- 어떤 이브이든 Lv50 도달 시 자동 발동
- 효과 (반경 150 안 모든 이브이즈, 10초):
  - 모든 스킬 쿨다운 즉시 초기화
  - ATK/spAtk ×1.5
  - 사거리 ×1.3, 공속 ×0.65
- 20초 쿨다운

## 일반공격 vs 스킬

### 일반공격 (평타)
- 매 `effSpd` 프레임마다 1회
- atk 사용, 몬스터 mDef로 방어
- 항상 phys 카테고리

### 스킬 (진화체별 2개)
- **Lv5**: 1번째 스킬 (Ⓟ 물리)
- **Lv10**: 2번째 스킬 (Ⓢ 특수)
- 발동: 평타 시점에 **10% 확률** + 쿨다운 OK
- 첫 사용은 쿨다운 절반에서 시작 (빠른 첫 발동)

### 이펙트 타입
| 타입 | 설명 |
|---|---|
| single | 단일 강타 (광선 + 폭발) |
| melee | 근접 (이빨 마크 + 폭발, 빔 없음) |
| dash | 돌진 (잔상 라인 + 임팩트) |
| aoe | 광역 (대상 주변 원형 데미지) |
| chain | 연쇄 (가까운 적 3마리 점프, 번개 라인) |

### 스플래시 데미지
- single / melee / dash / chain 스킬은 적중 위치에 **반경 25 스플래시** (40% 데미지)
- aoe는 그 자체가 광역이라 스플래시 X

### 데미지 공식
```
물리 = max(1, atk × mul - mDef × 0.3) × 타입상성
특수 = max(1, spAtk × mul - sDef × 0.3) × 타입상성
```

### 상태이상
| 상태 | 효과 |
|---|---|
| 화상 (burn) | 30프레임마다 DOT |
| 독 (poison) | 30프레임마다 DOT |
| 빙결 (freeze) | 이속 40% (느림) |
| 마비 (paralysis) | 이속 0 (정지) |
| 잠듦 (sleep) | 이속 0 (정지) |
| 방어약화 (defDown) | mDef/sDef -30% |

각 스킬마다 상태이상 + 발동 확률 부여 (예: 부스터 화상 30%, 글레이시아 빙결 25%).

## 게임오버 (농장 과포화)
- 필드 살아있는 몬스터 ≥ **50** OR 보스 ≥ **2**
- 카운트다운 **15초** 시작 (위쪽 화면)
- 줄어들면 카운트다운 해제, 다시 발동 시 처음부터
- 카운트다운 끝까지 안 줄면 게임오버
- 컷신: 몬스터들이 농장 안쪽으로 침투 + 떨림 + "농장이 침입당했다!"

## 골드/경제
- 시작 골드: 50
- 일반 처치 보상: `6 + floor(wave * 1.0)`
- 보스 처치 보상: `60 + wave * 12`
- 레이드 처치 보상: `150 + wave * 20`
- 사용처: 이브이 추가 / 진화 / 레벨업

## 인터랙티브 튜토리얼 (5단계)
첫 실행 시 자동 표시. localStorage `eevee2_tutorial_seen` 저장.
1. **이브이 탭** — 선택
2. **드래그 → 목표 지점 (◎)** — 농장 우측 펄스 원형으로 이동
3. **자동 공격** — 차곡차곡 1마리 자동 등장 → 처치
4. **레벨업** — 좌측 ▲ 강조, 1회 레벨업
5. **이브이 추가** — + 이브이 버튼 강조, 1회 추가 → 자동으로 정식 게임 시작

- 우측 하단 **스킵** 버튼
- 튜토리얼 중 웨이브/과포화 비활성
- 스플래시 화면 우측 하단 ? 버튼으로 다시 보기 가능

## 랭킹 리더보드 (Apps Script)
- 기록 항목: **닉네임, 도달 웨이브, 진화 수**
- 게임오버 → 닉네임 입력 모달 → 자동 제출
- HUD 우측 상단 🏆 버튼 → TOP 10 팝업
- 스플래시 화면 TOP 3 미니 표시
- **localStorage deviceId** 발급 → 같은 닉네임이라도 다른 디바이스면 별개 행
- 모바일 닉네임 입력은 숨겨진 HTML `<input>` 활용 (iOS Safari 키보드 호환)
- 확인/취소 버튼 (모바일 Enter 대체)

## HUD
- **상단 좌측**: 낮/밤 배지
- **상단 좌측 (배지 아래)**: 인벤토리 (보유 아이템 아이콘)
- **상단 중앙**: 웨이브 배지 + 30s 타이머 + 필드 N/50 + 잔여
- **상단 우측**: 🏆 리더보드 / 코인 ($) / (드래그 중) 판매 슬롯
- **하단 바**: + 이브이 (30g) / 슬롯 표시 / 보유 마릿수
- **선택 시 좌측**: 액션 패널 (Lv / ♥ / ▲ 레벨업)
- **선택 시 하단**: 상점(이브이) / 진화체 정보+스킬 게이지 / 몬스터 정보 / 바위 정보 / 아이템 정보
- **카운트다운**: 화면 가장자리 빨강 펄스 + 중앙 카운트다운
- **컷신**: 몬스터 침입 + "농장이 침입당했다!"
- **게임오버**: 도달 웨이브 + 닉네임 입력 → 재시작
